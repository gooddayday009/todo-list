# 群机器人通知与切换体验

设置页底部的「群机器人通知」支持企业微信、飞书、钉钉，各平台独立开关，可以同时启用。

1. 在目标群创建自定义机器人，复制平台生成的 Webhook 地址。
2. 填入对应平台配置；飞书、钉钉开启加签时填写签名密钥。
3. 如设置关键词校验，关键词可使用 `weldd`，测试通知和任务提醒都包含该词。
4. 点击「发送测试消息」会向该群发送一条消息，使用当前表单内容，不会自动保存配置。
5. 点击「保存通知配置」后，到期提醒和启动时的错过提醒会发送到所有已启用的平台。

应用必须处于运行状态才能发送；关闭期间错过的提醒会在下次启动时汇总。本地弹窗保留，网络发送独立运行，单次超时 10 秒，失败不会自动重试。当前只发送任务标题，不发送备注。长批次会截断并提示在应用内查看。

Webhook 地址、密钥保存在 `%APPDATA%/com.weldd.app/settings.json`，属于本地明文配置；界面使用密码输入框遮挡，不在错误信息中回显令牌。任务 JSON 导出不包含通知配置。

协议参考：[飞书自定义机器人](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot)、[钉钉安全设置](https://open.dingtalk.com/document/robots/customize-robot-security-settings)、[企业微信群机器人](https://developer.work.weixin.qq.com/document/path/91770)。

## 切换体验

- 胶囊与面板切换时保留面板实例，固定内容高度，以窗口裁剪呈现展开/收起，避免反复挂载与透明度动画叠加。
- 悬停、点击、鼠标离开和 Rust 形态事件统一取消过期计时器，避免刚收起又展开。
- 原生缩放帧在主线程实际执行时检查代际，过期帧不会覆盖新形态。
- 设置页及输入期间不自动收起，保留胶囊/面板切换中的输入草稿。

## 验证

- `pnpm build`
- `cargo check`（配置 cargo PATH 后在 src-tauri 运行）
- Windows 下运行 `test-rust.bat`：验证三平台消息结构、独立计算的签名向量、非法地址和业务错误码。
- `build-release.bat`：生成应用及 NSIS 安装包。
- 退出旧实例后运行 `geometry-test.ps1 -ExePath <新 weldd.exe 路径>`；已有位置/形态配置会影响首启断言，应在独立测试用户下验证默认几何。
- 现场检查快速悬停/离开、连续展开/收起、设置/历史切换、停靠滑出，以及真实群机器人测试和任务到期投递。
